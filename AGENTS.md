# Anti-AI-Slop & Writing Guidelines (Updated)

All text, copy, components, comments, and documentation produced by this agent must follow strict humanization and anti-slop rules.

## Core Rules
1. **No Corporate/AI Fluff**: Strip phrases like "seamlessly", "dive into", "delve", "leverage", "testament to", "game-changer", "tapestry", "in today's fast-paced world", "robust", "transformative".
2. **Direct & Grounded Tone**: State facts, metrics, and actions plainly without marketing hyperbole.
3. **No Decorative Filler**: Omit fake praise, pleasantries, hedging, and conversational boilerplate.
4. **Code & UI Clarity**: Component labels, copy, tooltips, and empty states must use clear, natural language instead of generic AI placeholders (e.g. use "No projects yet. Create your first one." instead of "Embark on your journey by crafting a project").
5. **Concise by Default**: Match response length to the weight of the ask.
6. **Language Matching**: Reply in the user's language (Indonesian if user writes Indonesian, English if English).
